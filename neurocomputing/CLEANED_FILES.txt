Public copy: files of neurocomputing/ that differ from the files the re-analysis wrote

The re-analysis ran in a project tree on the author's machine (folder neuro/reanalysis, mirrored here as
neurocomputing/). Before publication (20 November 2026) the copies listed below were changed. Every other file added
together with this note is byte-identical to the file the re-analysis wrote or is its xz-compressed copy
(XZ_ORIGINALS.sha256 gives the SHA-256 of each decompressed file); XZ_ORIGINALS.sha256 and this note were written
for the publication.

Hash records written before publication refer to the original bytes. The records that name a changed file:
- results/FAST_BATTERY.md5: the md5 values of check_cpu_dinov2/eval_check.json, check_cpu_dinov2reg/eval_check.json,
  check_cpu_iie/eval_check.json, check_cpu_siglip/eval_check.json, results/fast_battery_gates.json and
  results/fast_battery_outputs.json refer to the files before the path cleaning of section 1. Two more entries no
  longer match for another reason: DEVIATIONS.md and logs/score_rigid.log were appended to after the record was
  written.
- results/fast_battery_outputs.json: its md5 values of the four check_cpu_*/eval_check.json files refer to the files
  before the path cleaning.
No file listed in REANALYSIS_RULE.sha256 or in results/explore_scripts.sha256 was changed.
