- Why it is logged: a fixed file uses a convention the rule text does not contain; the file was not edited.
- Results seen: P1 to P4 (out/primary_P1_P2_P3_P4.json). Effect on decisions: none. Under either convention the same 8 of 18 P4 contrasts are counted (verify_rescore/recompute_stats.json keys P4.n_counted and P4.n_counted_clip; every other BCa p, every BCa interval, z0 and acceleration agree with the reported values to 3.2e-15).
