# Responses to the two reviews of the re-analysis rule

- Written 18 November 2026, after `reviews/stats_review.md` (statistics and honesty; 4 BLOCKER, 17 SHOULD-FIX, 14 NOTE) and `reviews/design_review.md` (rigid-rotation stimuli, P5, scoring and run plan; 2 BLOCKER, 6 SHOULD-FIX, 10 NOTE), and before the rule was fixed. Both review notes are copied byte for byte into `reviews/`; the reviewers' scripts and outputs are in `reviews/support/` (not hashed).
- Procedure for every BLOCKER and SHOULD-FIX: reproduce it first (from the result files, the code, a read-only git query, a live process check, or a synthetic case run against the pre-review code kept in `neuro/_trash/analyze_re_before_review_20261118.py`); if real, fix it in the rule, the code or the stimuli and rerun the tests; if not, say why.
- Outcome: every BLOCKER and SHOULD-FIX was reproduced and is real. None was rejected. All were fixed before `fix_rule.py` ran. The NOTE items were applied where they asked for a change.
- Nothing was scored: no model or null was run on any stimulus. CPU work: JSON reads, the renderer (stimuli only), the unit tests (synthetic data), one feature-path check on a synthetic noise image (three backbones on the CPU; its process held no Metal client), and read-only `ps`, `ioreg` and `git log` queries.
- Tests after the changes: `tests_output.txt` 73 checks, 0 failed (was 49); `tests_features_output.txt` 14 checks, 0 failed.

## Choices made while fixing, which the author can still change before the push

1. Title condition (c0): at least two valid non-R4 readouts on each title-bearing feature set (the smallest number on any feature set of the published swap). D6 read literally would pass a feature set with no valid comparison; both reviewers flagged that. If the author prefers one, change `MIN_VALID` in `analyze_re.py` and the number in rule Section 5.6 before the push.
2. Condition (d) with an undefined reference: any valid cell whose interval excludes zero counts as an interval of the opposite sign (the statistics reviewer's recommended reading; the alternative, "(d) is not evaluated on that set", is weaker).
3. Orientation-matched controls rendered at theta = 10, 20 and 30 (180 displays; the design reviewer's recommended option; MSDB about 79 min more than the required theta = 20 alone).
4. P5 category 2 split into 2a "shrinks" and 2b "half criterion undecided" (design review finding 3), with the abstract consequence unchanged.
5. Open exploratory options closed (statistics review note 33): MSI-Net calibration by rank equalisation only; the point-spread probe of A11 is not run.
